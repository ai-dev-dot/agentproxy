# AgentProxy

One API Key, All Models, Any Agent.

AgentProxy is a transparent LLM proxy that allows Claude Code, Cursor, Windsurf and any other agent to use multiple LLM providers simultaneously with a single API key. It solves the biggest limitation of modern agents: they can only use one model provider at a time.

## Why AgentProxy?

- 🚀 **Use the best model for each task**: Code generation with DeepSeek, long context with Mimo, tool calling with MiniMax
- 🔑 **Single API key**: Configure your agent once and never change it again
- 🔄 **Smart routing**: Automatically route requests to the optimal model based on task type
- 📊 **Cost monitoring**: Track and optimize your LLM usage across all providers
- 💻 **100% OpenAI compatible**: Works with any tool that supports OpenAI API
